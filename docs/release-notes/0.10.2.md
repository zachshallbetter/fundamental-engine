# 0.10.2

**2026-10-11**

Patch release after 0.10.1 (2026-07-21). Full notes: [CHANGELOG](../../CHANGELOG.md#0102--2026-10-11).

## Highlights

- Capability gates `read:snapshots` and `read:diagnostics` enforced on agent views (tighten-only).
- Fractional `budgets.agentRead` enforced across planes.
- Swift diagnostic probes no longer mutate live simulation state.
- Kotlin force catalog generated in lockstep; parser no longer drops rows silently.
- Rust plane: CMS reading layer, scalar grids / class-[C] forces, `screen`, `collide`, `fieldflow`, spawn/morph, and related substrate work (still experimental for crates.io).
- Site calm-instrument homepage pass; assorted CI/tooling and docs-gate fixes.
- `BodySpec.absorbR` available on all three application planes.
- Repository release/publish policy docs moved under `docs/meta/`.

## Version lockstep

npm packages, `FIELD_VERSION` (JS / Swift / Kotlin / Rust), and citation metadata all track **0.10.2**.

## Distribution

GitHub release tag is cut at **v0.10.2**. npm provenance publish requires a valid `NPM_TOKEN` with write access to `@fundamental-engine` (CI returned `E404` on PUT for `0.10.2` after signing provenance — typically expired or mis-scoped token).

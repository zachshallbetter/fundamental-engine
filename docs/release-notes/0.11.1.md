# 0.11.1

**2026-10-14**

Patch release for the fixes from the 2026-10-14 engine audit. Every change is a bug fix, a performance
fix, documentation, or tooling; the only API addition is `QualityGovernor.setBudget()` / `.budgetMs`
(additive), so this is a patch under the [versioning policy](../meta/releasing.md).

## Upgrade if you use

- **`npm create @fundamental-engine`** — it exited 0 and created nothing in every release from 0.9.3 to
  0.11.0 (npm runs the bin through a `.bin` symlink; the entrypoint guard never matched). It now
  scaffolds, installs the current engine (`^0.11.0`, not `^0.9.2`), and the React starter typechecks.
- **`<field-cell>` under a bundler** — it was tree-shaken out by `sideEffects` and never registered.
- **SPA navigation (Astro view transitions, framework unmounts)** — removed `[data-body]` elements no
  longer act as bodies at the top-left corner, and `destroy()` from inside a field callback no longer
  leaves the loop running.
- **Mobile** — the address bar showing/hiding no longer rebuilds the particle swarm; `<field-root>`'s
  quality governor uses the display's real frame budget, so a 30 Hz display isn't held at tier 2.
- **The grid / any static overlay** — an unchanged overlay frame is no longer re-rastered.

## Also

- Documentation truth pass: README and package READMEs state what the code does (render modes, query /
  snapshot / replay, reduced motion, force counts, Rust plane 36/37), and every README TypeScript block
  is now typechecked in CI (`check:readme-code`).
- New `check:consumer` gate: scaffold → install the packed tarballs → typecheck → build, blocking in the
  release workflow.

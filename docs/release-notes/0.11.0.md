# 0.11.0

**2026-10-11**

Milestone minor after the Jul–Oct catch-up. Interim packaging was [0.10.2](./0.10.2.md); this release is the lockstep fleet version that matches the product story.

## Why minor

Under the pre-1.0 cadence rule, this batch includes:

- experimental **Rust plane** (`fundamental-core`)
- **enforced** agent capabilities (`read:snapshots`, `read:diagnostics`, fractional `agentRead`)
- **height-aware / terrain** fields and related substrate work
- CMS reading layer (Rust), overlays, resting-motion, and the rest of the 0.10.2 changelog

Those should not remain forever labeled as a single patch on 0.10.1.

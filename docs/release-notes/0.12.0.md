# 0.12.0

**2026-11-03**

A navigation milestone. The engine's forces have always been *reactive* — they read the local
field and push — which is right for matter and wrong for an agent with somewhere to be. This
release adds a real wayfinding subsystem, makes the cursor a first-class participant in the
field, and gives "something just happened, here" its own channel.

## Why minor

Under the pre-1.0 [cadence rule](../meta/releasing.md#release-cadence-pre-10), a coherent
milestone is cut as a minor even when every change is additive and a patch would be
policy-legal — so the number matches the story people read on npm and in citations. This batch
includes a new navigation subsystem and two new interaction surfaces:

- **NavGrid** — obstacle-aware navigation and goal flow-fields (#439): an occupancy grid plus a
  breadth-first sweep from the goal, so a thousand seekers cost one sweep and none walks into
  the near side of a wall.
- **Pointer dynamics and throw** (#666): `field.pointer()` / `clearPointer()` make the cursor a
  real body whose *velocity* entrains matter, and `field.fling()` releases a dragged element
  into the field's own dynamics.
- **`field.pulse()`** (#567): a decaying one-shot flare on its own `--field-pulse` channel —
  neither a `burst` (it moves no matter) nor `--d` (it measures nothing), proven by test.
- **`render: 'lic'`** (#671): the force field drawn as texture rather than arrows.
- **Tab order as a field current** (#943): `--field-next` marks the body Tab reaches next, a
  static cue that satisfies the reduced-motion contract by construction.

## Also

- **Observer-driven measurement** (#689) — the engine stops polling a page that is not moving:
  10 rect reads per 60 frames → 2, asserted as exact counts.
- **Contained fields stop when their box scrolls out of view** — an off-screen card's feedback
  writes drop from 13 per 1.2 s to 0, resuming on return.
- **One overlay vocabulary, checked in both directions** — `OVERLAY_MODE_LIST` /
  `OVERLAY_READING_LIST` close the four-copy drift that let a reading be dropped silently.
- **`render: 'none'` no longer silences the overlay** — a signals-only field can still draw a
  reading; the canon is amended on the record.
- Fixes: the simulation clock starts at the first frame (#1207), Kotlin warp pairing is
  reachable through the public body API (#1175), and the x-ray hotkey ignores editable fields.

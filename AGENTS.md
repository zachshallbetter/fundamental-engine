# AGENTS.md

Repository-wide instructions for AI agents and people working anywhere in this repository.

**Read [`.agents/AGENTS.md`](.agents/AGENTS.md) first.** It is the entry point to the shared knowledge
base: what this repository is, the non-negotiables (no unverified claims; no release, tag, publish or
merge unless the maintainer asks for that specific one; never rewrite shared history; regenerate
generated artefacts instead of hand-editing them; one git worktree per task), the working loop, and
the runbooks (workflow, gates and CI, release, verification, sites) and knowledge files (engine facts,
pitfalls, open work) that go with it.

Those rules apply to all work in this repository — `packages/`, `swift/`, `android/`, `rust/`,
`apps/`, `docs/`, `scripts/` — not only to files under `.agents/`.
